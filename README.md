## 📌 Featured Projects

### 🔐 [classical-cryptanalysis-toolkit](https://github.com/ebenjamin12/classical-cryptanalysis-toolkit)
Classical cryptanalysis in **Haskell** — Caesar and Vigenère ciphers, frequency analysis, and Kasiski examination — paired with a cryptarithm solver that encodes puzzles as constraints for the **Z3 SMT solver** in Python. The same reasoning done two ways: by hand in a pure functional language, and declaratively through a solver.
`Haskell` · `Python` · `Z3 / SMT`

### ☕ cafe-booking-inventory-system &nbsp; 🚧 *In progress*
A **Django** web app for small cafés: table reservations with pre-orders that automatically deduct ingredient stock, plus a 7-day reorder forecast. Ties the front-of-house booking flow directly to back-of-house inventory.
`Python` · `Django` · `SQLite`

### 📊 amazon-reviews-pyspark-ml &nbsp; 🚧 *In progress*
A distributed **PySpark** ML pipeline over **12.2M Amazon reviews** predicting whether a purchase was verified — with a majority-class baseline analysis showing why a high F1 score can mislead on imbalanced data. As much about honest evaluation as about the model.
`PySpark` · `Spark MLlib` · `Python`
